**Phase:** 0 · **Owner agent:** `golive-operator` · 👤 **Owner required:** no (but is the recipient of the single test email)
**Depends on:** T0.2 gate recorded in `orchestration/STATE.md`.
**Sources:** `utils/safety.js` (all three guards); `email/send.js` (guard ordering: allowlist at line 101 runs even for dryRun; dryRun returns at line 157 **before** the rate-limit counter at line 162); `CLAUDE.md` §"Safety Controls"; `HANDOVER.md` §"Live Smoke Test Order" ("When testing sending later").

## Objective

Demonstrate, with recorded evidence, that each of the three send guards actually blocks/previews on the live server. Exactly **one** real email is sent, to the owner's own address.

## Preconditions

- Server session env: `OUTLOOK_ALLOWED_RECIPIENTS=<owner-address>` (T0.1) and, for step 3, a restart with `OUTLOOK_MAX_EMAILS_PER_SESSION=1`.
- Re-run smoke checks 1–2 (auth status/about) after any server restart before proceeding.
